# UK product research, latest results

The latest run of a UK product research tool for pet products, toys and tech gadgets.
It reads Amazon UK Best Sellers and Hot New Releases, checks each product against UK
Google Trends and AliExpress supplier prices, and scores it out of 100 with the reason
for every part of the score.

Open the page: https://mirzasaghar.github.io/uk-product-research/

`data.json` holds the results of the most recent run. Every figure carries the time its
source was read. The margin is the only estimate.
